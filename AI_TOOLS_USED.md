# AI Tools Used

## Tools & Usage

| Tool | Purpose |
|------|---------|
| **Google Gemini (Antigravity)** | Primary AI assistant used for generating the complete project structure, all source code files (models, controllers, views, CSS, JS), database scripts, and documentation. Used for architectural decisions, code generation, and project scaffolding. |

## How AI Was Used

1. **Project Architecture & Design**: Used AI to help plan the database schema, MVC project structure, and feature set based on the requirements.

2. **Code Generation**: Generated all C# source files including:
   - Entity Framework models with data annotations
   - ASP.NET Core Identity user model
   - MVC Controllers with business logic
   - ViewModels for clean separation of concerns
   - Razor views with Bootstrap 5 responsive UI
   - Custom CSS and JavaScript

3. **Database Script**: Generated the complete SQL Server schema script with sample seed data.

4. **Documentation**: Generated README.md with design decisions and setup instructions.

## Human Contributions

- All design decisions regarding features, business rules, and architecture
- Review and verification of generated code
- Project requirements analysis and prioritization
- Testing and quality assurance
